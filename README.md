## Proximal-MAD-GAN

A multi-agent GAN benchmark with an adjusted game objective, inspired by Multi-Agent Diverse GAN and equilibrium concepts from "Do GANs Have Nash Equilibria?".

### About

Reproduces experiments from the original MAD-GAN papers with a modified game payoff function. Computes the same metrics reported in the original work.
